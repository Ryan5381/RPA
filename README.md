## 🚀 專案架構

本專案採用前後端分離架構設計：

- **前端控制台 (React + Vite + Tailwind CSS)**：提供即時的自動化任務監控、排程狀態以及控制操作介面。
- **後端自動化引擎 (Python + FastAPI)**：負責核心 RPA 自動化流程執行、驗證碼處理，並透過 WebSocket 提供即時日誌串流。

## 📦 前端本機啟動方式

1. 進入前端目錄：
   ```bash
   cd frontend
   ```
2. 安裝套件：
   ```bash
   npm install
   ```
3. 本地開發模式啟動：
   ```bash
   npm run dev
   ```
